# Intellicloud

This cloud service is no longer available, as Intellinode is now fully open source.
If you’d like access to the vector project, please contact alex@intellinode.ai

## What to try instead

The open source library covers the same ground, and you can run it from your own environment:

- [Chatbot](/docs/python/chatbot/get-started): one unified input to openai, anthropic, gemini and mistral, with model switching that needs no code change.
- [Flows](/docs/python/flows/get-started): connect several models and tools into one workflow, in sequence or as a graph.
- [Computer use](/docs/python/flows/computer-use): let an agent operate a browser when the system you need has no API.
- [Coding agent](/docs/python/flows/coding-agent): let an agent edit a workspace and run its tests.
